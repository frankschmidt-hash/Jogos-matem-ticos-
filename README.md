# Jogos Matemáticos

Ambiente virtual educacional para estudantes do 5º ao 7º ano.

## Jogos planejados
- Banco Imobiliário Matemático
- Corrida Maluca
- Corrida Numérica
- Futebol Matemático

## Estado
- Prompt 00: arquitetura e governança concluídas.
- Prompt 01: fundação da plataforma em implementação.

A V1 usa acesso sem cadastro, apelido temporário exclusivo, motor matemático compartilhado e infraestrutura preparada para partidas em tempo real.
