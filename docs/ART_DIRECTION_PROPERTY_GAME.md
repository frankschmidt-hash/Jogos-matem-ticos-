# Direção de Arte — Banco Imobiliário Matemático

## Identidade
O jogo usa uma identidade original chamada **Cidade Prisma**.

A linguagem visual combina:
- geometria;
- arquitetura urbana fictícia;
- elementos escolares discretos;
- cores por grupos de propriedades;
- moeda própria: **Créditos Prisma (CP)**.

## Assets originais incluídos
- `cidade-prisma.svg`: emblema urbano/prismático;
- `credito-prisma.svg`: símbolo da moeda CP;
- `trofeu-prisma.svg`: troféu de encerramento.

## Tabuleiro
- 36 casas;
- seis grupos de propriedades;
- casas de evento, bônus, imposto, serviço, transporte, descanso e penalidade;
- centro do tabuleiro com emblema Cidade Prisma;
- peças representadas por tokens coloridos;
- marca visual de proprietário e nível de melhoria.

## Grupos
- Horizonte;
- Prisma;
- Aurora;
- Circuito;
- Órbita;
- Saber.

## Diretriz de propriedade intelectual
Nenhum tabuleiro, nome de propriedade, cédula, carta, logotipo, peão ou layout comercial foi reproduzido.
Toda a identidade visual desta implementação é própria do projeto.
